# APS AI Project

Система искусственного интеллекта для автоматизации проектирования АПС (Автоматических Пожарных Систем).

## 📋 Обзор

Проект направлен на создание AI-ассистента для инженеров по пожарной безопасности, способного:
- Анализировать планы зданий
- Распознавать условные обозначения оборудования
- Извлекать спецификации из проектной документации
- Предлагать оптимальные решения по размещению оборудования

## 📁 Структура проекта

```
aps_ai_project/
├── data/                    # Данные
│   ├── raw/                # Исходные данные
│   │   ├── projects/       # Проекты
│   │   ├── pprog/          # .pprog файлы
│   │   └── plans_pdf/      # PDF планы

│   └── convert_plans.py    # Конвертер планов
├── models/                 # Модели ML
├── configs/                # Конфигурации
└── docs/                   # Документация
    └── data_collection_guide.md
```

## 🚀 Быстрый старт

### Установка зависимостей

```bash
# Системные зависимости
sudo apt-get install poppler-utils  # Для конвертации PDF

# Python зависимости
pip install Pillow opencv-python ultralytics transformers
```

### Использование скриптов

**Парсинг .pprog файлов:**
```bash
python scripts/parse_pprog.py data/raw/pprog/ -o data/processed/parsed_pprog/
```

**Конвертация планов:**
```bash
python scripts/convert_plans.py data/raw/plans_pdf/ -o data/processed/plans --dpi 300 --normalize
```
