# План сбора данных для АПС AI

## 1. Источники данных

### Проекты с документацией (цель: 50+)
- Архивные проекты компании
- Публичные проекты (если доступны)
- Партнёрские организации

### Файлы .pprog (цель: 50+ образцов)
- Извлечь из проектов
- Сохранить структуру и метаданные

### Изображения планов (цель: 1000+ размеченных)
- Сканеры/экспорты из САПР
- Форматы: PNG, TIFF, PDF → конвертация

---

## 2. Структура каталогов

```
data/
├── raw/              # Исходные данные
│   ├── projects/     # 50+ проектов
│   ├── pprog/        # .pprog файлы
│   └── plans/        # Изображения планов
├── processed/        # Обработанные данные
│   ├── parsed_pprog/ # Распарсенные .pprog
│   └── normalized/   # Нормализованные планы
└── annotated/        # Размеченные данные
    ├── yolo_labels/  # Для YOLOv8
    └── ner_texts/    # Для NER модели
```

---

## 3. Инструменты для сбора

### Парсер .pprog файлов
- Анализ структуры файла
- Извлечение спецификаций
- Экспорт в JSON/CSV

### Конвертер планов
- PDF → PNG/TIFF
- Нормализация разрешения
- Удаление шума

### Инструмент разметки
- CVAT / LabelImg / Custom UI
- Классы: датчики, шлейфы, приборы, зоны

---

## 4. Метрики качества данных

| Метрика | Целевое значение |
|---------|------------------|
| Количество проектов | 50+ |

| Размеченных изображений | 1000+ |
