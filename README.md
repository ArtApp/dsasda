# Project-to-PProg

Инструмент автоматизации конфигурирования приборов охранно-пожарной сигнализации «Болид» (PProg) на основе проектной документации.

## 📖 Описание

**Project-to-PProg** — это настольное приложение, которое автоматически извлекает данные из PDF-файлов проектной документации и генерирует конфигурационные файлы для программы PProg, используемой для программирования приборов серии С2000 производства НВП «Болид».

Инструмент значительно сокращает время на ручное внесение данных из проекта в конфигурацию PProg, минимизируя вероятность ошибок и обеспечивая соответствие конфигурации проектным решениям.

## ✨ Возможности

- **Автоматический парсинг PDF** — извлечение данных о устройствах, разделах, зонах и исполнительных устройствах из проектной документации
- **База знаний оборудования** — справочник устройств «Болид» с маппингом на внутренние типы PProg
- **Интерактивный редактор** — GUI для просмотра и ручной корректировки распарсенных данных
- **Валидация конфигурации** — проверка на дубликаты адресов, пустые обязательные поля, несовместимые типы
- **Экспорт в форматы PProg** — генерация текстовых файлов конфигурации, совместимых с PProg
- **Поддержка нескольких форматов** — экспорт в TXT, JSON, Excel

### Основные модули

#### 1. Парсер проектной документации (`modules/pdf_parser.py`)
Извлекает структурированные данные из PDF:
- Типы устройств (С2000М, С2000-КДЛ-2И, С2000-СП2 и др.)
- Сетевые адреса устройств (ARK, SC, BTH...)
- Разделы (Partitions) и зоны (Zones)
- Исполнительные устройства (Relays) и алгоритмы управления

**Технологии:** PyMuPDF, регулярные выражения, pandas

#### 2. База знаний по оборудованию (`data/equipment_db.py`)
JSON-справочник, связывающий модели устройств из проектов с их внутренними идентификаторами в PProg:

```python
{
  "ДИП-34А-03": {
    "pprog_type": "Addressable Smoke Detector",
    "zone_type": "Smoke Analog Addressable",
    "algorithm": "B"
  },
  "ИПР 513-ЗАМ исп.01": {
    "pprog_type": "Addressable Manual Call Point",
    "zone_type": "Manual Call Points",
    "algorithm": "A"
  }
}
```

#### 3. Интерактивный редактор (`gui/main_window.py`)
GUI на PySide6 с компонентами:
- Дерево объектов (разделы, устройства, реле)
- Инспектор свойств для редактирования параметров
- Страницы для ручного ввода (Devices, Partitions, Relays, Management Scenarios)
- Валидатор в реальном времени

#### 4. Генератор выходного файла (`modules/exporter.py`)
Преобразует внутреннее представление конфигурации в формат PProg (.txt).

#### 5. NLP-анализатор (`modules/nlp_analyzer.py`)
Использует spaCy и pymorphy3 для семантического анализа текста проектной документации.

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- Операционная система: Windows, Linux, macOS

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd Project-to-PProg
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```

### Пример использования

```python
from main import create_app

# Создание экземпляра приложения
app = create_app()

# Загрузка PDF проекта
result = app.load_pdf("path/to/project.pdf")

# Проверка сводки
summary = app.get_summary()
print(f"Устройств: {summary['devices_count']}")
print(f"Разделов: {summary['partitions_count']}")
print(f"Зон: {summary['zones_count']}")

# Валидация конфигурации
errors = app.validate_configuration()
if errors:
    print("Ошибки валидации:")
    for error in errors:
        print(f"  - {error}")

# Экспорт в файл
app.export("output/config.txt", format="txt")
```

### Быстрый экспорт

```python
from main import quick_export

# Парсинг и экспорт в одну строку
quick_export("project.pdf", "output/config.txt")
```

## 🔧 Технологический стек

- **Язык:** Python 3.10+
- **GUI:** PySide6 (PyQt6)
- **Парсинг PDF:** PyMuPDF + pandas
- **NLP:** spaCy + pymorphy3 + ru_core_news_sm

## 📁 Структура данных

### Configuration
Основная модель конфигурации, содержащая:
- `project_name` — имя проекта
- `devices` — список устройств (адрес, тип, версия)
- `partitions` — разделы с зонами
- `zones` — зоны (извещатели)
- `relays` — реле и исполнительные устройства
- `scenarios` — сценарии управления

### Device Types
Поддерживаемые типы устройств:
- С2000М — Прибор управления
- С2000-КДЛ-2И — Контроллер ДПЛС
- С2000-СП2 — Прибор релейный
- С2000-БКИ — Блок клавиатурный
- ДИП-34А — Дымовой извещатель
- ИПР 513-3А — Ручной извещатель
- И другие устройства серии С2000

## ⚠️ Важные замечания

1. **Формат PProg:** Для корректного экспорта необходима документация на текстовый формат PProg от НВП «Болид». Если документация недоступна, выполняется обратная разработка формата.

2. **Ручная проверка:** После автоматического парсинга рекомендуется проверить конфигурацию в редакторе и выполнить валидацию перед экспортом.

3. **Импорт в PProg:** Сгенерированный файл импортируется в PProg через меню `File → Open`, затем записывается в прибор через `S2000 → Write Configuration`.
