# 🗺️ ROADMAP: Project-to-PProg

Дорожная карта развития системы автоматизации конфигурирования приборов «Болид».

---

## 📊 Текущий статус (v0.4.0 - Beta)
**Дата:** Октябрь 2023
**Готовность ядра:** 85%
**Готовность GUI:** 70%
**Покрытие тестами:** 68 тестов (~88%)

### ✅ Реализовано в текущей версии:
- [x] Парсинг PDF спецификаций (таблицы, текст, кириллица)
- [x] База знаний (>40 устройств Болид)
- [x] Модели данных (Device, Zone, Partition, Scenario)
- [x] Генератор выходных файлов (TXT для PProg, JSON, Excel, HTML)
- [x] GUI интерфейс (PySide6) с таблицами и редактором
- [x] Валидатор конфигураций (адреса, типы, связи)
- [x] Конфигуратор сценариев управления (логика, таймеры)
- [x] Сетевая модель (топология "Кольцо", "Луч", валидация линий)
- [x] Архитектура плагинов (расширяемость парсеров и экспортеров)
- [x] CLI интерфейс для пакетной обработки
- [x] Юнит-тесты и интеграционное тестирование

## 🚀 Этап 1: Стабилизация и Полировка (v0.5.0)
**Срок:** 1 месяц
**Цель:** Подготовка к пилотному внедрению на реальных объектах.

### 1.1 Улучшение парсинга (Priority: High)
- [ ] **Эвристический анализ текста:** Внедрение NLP (spaCy/ruNLP) для лучшего понимания контекста в описательной части проектов.
- [ ] **Распознавание схем:** Интеграция OpenCV/Tesseract для чтения адресов с графических схем (планов этажей), если они есть в PDF.
- [ ] **Обработка сканов:** Улучшение работы с некачественными сканами (шум, перекос, низкое DPI).
- [ ] **Шаблоны проектов:** Создание профилей парсинга под типовые проектные бюро (разные форматы спецификаций).

### 1.2 Развитие GUI (Priority: Medium)
- [ ] **Drag-and-Drop:** Визуальное создание связей "Раздел -> Реле" перетаскиванием.
- [ ] **Визуализация топологии:** Графическое отображение сети (кольцо/луч) с индикацией проблемных участков.
- [ ] **Мастер настройки:** Пошаговый визард для быстрой первичной настройки проекта.
- [ ] **Темная тема:** Поддержка системной темы оформления.

### 1.3 Тестирование и Документация (Priority: High)
- [ ] **Сбор реальных кейсов:** Тестирование на 10+ реальных проектах разной сложности.
- [ ] **User Manual:** Написание подробного руководства пользователя с скриншотами.
- [ ] **Video Tutorials:** Запись серии видеоуроков (5-10 мин каждый).

## 🏗️ Этап 2: Продвинутая функциональность (v0.6.0 - v0.7.0)
**Срок:** 2-3 месяца
**Цель:** Расширение возможностей для сложных объектов и командной работы.

### 2.1 Сложная логика и Автоматизация
- [ ] **Графический редактор сценариев:** Нодовый интерфейс (как в Blender UE) для построения сложной логики без кода.
- [ ] **Библиотека шаблонов:** Готовые пресеты сценариев ("Школа", "Склад", "Офис", "Жилой дом").
- [ ] **Генерация ПНР:** Автоматическое создание чек-листов для пусконаладочных работ.

### 2.2 Командная работа и Версионирование
- [ ] **Git-интеграция:** Сохранение конфигураций в Git, поддержка веток и мержа изменений.
- [ ] **Сравнение версий:** Diff-инструмент для сравнения двух конфигураций проекта (что изменилось?).
- [ ] **Комментарии и заметки:** Возможность оставлять комментарии к конкретным устройствам или разделам.

### 2.3 Экосистема и Интеграции
- [ ] **Импорт из CAD:** Пробная поддержка импорта данных из AutoCAD (.dxf) или Revit (.rvt).
- [ ] **Интеграция с Орион Про:** Чтение базы данных из существующих систем Орион Про для миграции.
- [ ] **Плагины сообщества:** Публикация SDK и репозитория для сторонних плагинов.

## 🛠 Технические долги (нужно рефакторить)
1. **Оптимизация памяти:** При загрузке больших PDF (>100Мб) наблюдается высокий расход ОЗУ.
2. **Типизация:** В старых модулях (`pdf_parser`) не везде проставлены Type Hints.
3. **Логирация:** Структурировать логи в формат JSON для удобного анализа.
4. **Зависимости:** Обновить PySide6 до последней стабильной версии и проверить совместимость.
